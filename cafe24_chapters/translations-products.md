# TRANSLATIONS PRODUCTS


## Translations products

```json
Endpoints    GET /api/v2/admin/translations/products
PUT /api/v2/admin/translations/products/{product_no}
```


### Translations products property list

| Attribute | Description |
| --- | --- |
| shop_no | 멀티쇼핑몰 번호 |
| product_no | 상품번호 |

| Parameter | Description |
